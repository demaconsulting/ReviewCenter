### RepositoryStore

![Storage Structure](StorageView.svg)

#### Purpose

`RepositoryStore` is the persistence of the registry of git repositories: the implementation of the Core
`IRepositoryStore` interface and the internal row type `RepositoryRecord` it maps. Its single responsibility is to store
registrations with their encrypted tokens, so that each change and its audit entry are written in one transaction and
a token can leave the database only through one dedicated method.

#### Data Model

`RepositoryStore` is an internal sealed singleton created with the context factory and the `AuditAppender`. It holds no
other state.

**The table** is `Repositories`, mapped by `ReviewCenterDbContext` from `RepositoryRecord`:

- `Id` — the primary key, generated by the database.
- `Name` — required, at most 40 characters, compared without regard to case (the `NOCASE` collation) and unique
  through a
  unique index.
- `Location` — required, at most 500 characters.
- `Username` — optional, at most 200 characters.
- `EncryptedToken` — optional, at most 4000 characters (a named constant); the text that `ICredentialProtector` returned.
- `Enabled` — whether the repository can be selected.
- `CreatedAt`, `UpdatedAt` — the times of creation and of the last change.

`RepositoryRecord` is the only type that holds `EncryptedToken`. Its conversion to the Core model `SourceRepository`
copies everything else and sets `HasToken`, so the encrypted text never appears in the model that is listed, shown, or
passed around.

There are no foreign keys, and no other table refers to a repository in this slice.

#### Key Methods

**AddAsync**: Stores a new registration with its audit entry.

- *Parameters*: `NewRepository repository`, `Func<SourceRepository, AuditDraft> audit` — builds the audit entry from the
  stored registration, so it can name the assigned identity.
- *Returns*: `SourceRepository`.
- *Postconditions*: The row exists, enabled, with `CreatedAt` equal to `UpdatedAt`, and the audit entry exists, or neither.
- *Algorithm*: Run through `AuditAppender.ExecuteAsync`: add the row, save to learn the identity, build the draft from the
  result. A unique violation of the name (SQLite extended error 2067) is turned into `DomainRuleException` for
  `RepositoryNameTaken` with the message "A repository with the name 'X' already exists."

**GetAsync**: Returns the registration of an identity, or `null`. **ListAsync** returns all registrations ordered by name
(ignoring case), then identity. Both read without tracking, in a short-lived context.

**GetEncryptedTokenAsync**: Returns the encrypted token of an identity, or `null` when there is none or no such
repository. It is the only way a token leaves the table.

**UpdateAsync**: Changes a registration with its audit entry.

- *Parameters*: `int id`, `RepositoryUpdate update`, `AuditDraft audit`.
- *Returns*: `SourceRepository` — after the change.
- *Preconditions*: The repository exists, otherwise `RepositoryNotFound` ("The repository does not exist.").
- *Algorithm*: Through `AuditAppender.ExecuteAsync`: load the row, set name, location, user name, and enabled; apply the
  token action (`Replace` stores the new encrypted text, `Clear` sets it to null, `Keep` leaves it); set `UpdatedAt` from
  the clock; save; return the draft. A name clash is `RepositoryNameTaken` as for adding.

#### Error Handling

A name that is already used (in any letter case) is `RepositoryNameTaken`; an unknown identity in an update is
`RepositoryNotFound`. Any other database failure propagates after the transaction has rolled back, with the audit
appender's gate released, as described for `AuditStore`. Reads never take the gate.

#### Dependencies

- **ReviewCenterDbContext** — the `Repositories` table.
- **AuditAppender** — the transaction and the audit chain.
- **IRepositoryStore**, **SourceRepository**, **NewRepository**, **RepositoryUpdate**, **AuditDraft**, and
  **DomainRuleException** — Core.
- **Entity Framework Core** and **Microsoft.Data.Sqlite** — queries and the unique-violation code.

#### Callers

- **RepositoryService** — the only caller, through the `IRepositoryStore` interface.
- **ServerHost** — registers the store as a singleton.
